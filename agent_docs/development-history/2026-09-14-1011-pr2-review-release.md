## Находка

`yd_bid_modifiers_get` на master был сломан полностью: любой вызов падал с ошибкой 8000
«Отсутствует обязательный параметр Levels» — API требует `Levels` в `SelectionCriteria`
и отдельные массивы `*AdjustmentFieldNames` вместо полей корректировок в `FieldNames`.
Обнаружено только живым вызовом: офлайн-тесты этого не ловят.
