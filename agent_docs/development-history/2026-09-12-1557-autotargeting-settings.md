# [2026-09-12 15:57] Настройки автотаргетинга

## Что сделано

- `yd_keywords_get` запрашивает все категории запросов и брендовые опции автотаргетинга.
- `yd_keywords_add` принимает `autotargeting_settings` при создании `---autotargeting`.
- Добавлен `yd_keywords_update` для изменения настроек существующего автотаргетинга.
- Добавлены офлайн-проверки схем и запросов к Direct API.

## Зачем

Веб-интерфейс показывает эти параметры в настройках группы, но Direct API предоставляет их через
специальный критерий сервиса Keywords. MCP раньше возвращал только его наличие, статус и ставку.
