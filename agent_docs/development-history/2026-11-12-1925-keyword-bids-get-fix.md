# [2026-11-12 19:25] Починка `yd_keyword_bids_get`

## Что сделано

- `FieldNames` сокращён до допустимых полей: `KeywordId`, `AdGroupId`, `CampaignId`, `ServingStatus`.
- `Bid` и `AuctionBids` перенесены в `SearchFieldNames` — это устраняет ошибку API 8000.
- Фильтр по ключевым фразам использует `KeywordIds` вместо несуществующего `Ids`.
- Добавлены офлайн-проверки запроса для `CampaignIds`, `AdGroupIds` и `KeywordIds`.

## Зачем

Direct API принимает ставки и данные торгов только в `SearchFieldNames`; старый код отправлял их
в `FieldNames` и падал с ошибкой 8000 ещё до выборки. Ответ возвращается как есть, поэтому целые
денежные значения в миллионных долях и `null` в `AuctionBids` не искажаются.
