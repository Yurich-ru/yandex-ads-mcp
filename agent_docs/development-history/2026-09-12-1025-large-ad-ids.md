# [2026-09-12 10:25] Длинные ID комбинаторных объявлений

## Что исправлено

- Поля ID объявлений в `yd_ads_get`, `yd_ads_update` и `yd_ads_action` принимают как обычные
  целые числа, так и десятичные строки.
- Перед запросом к Direct API строковые ID преобразуются в точный Python `int`.
- Добавлен офлайн-тест на ID `1921132329195330424`, который превышает безопасный диапазон
  JavaScript `Number`.

## Причина

Комбинаторные объявления получают 19-значные ID. MCP-клиент округлял значение при передаче как
JSON number, а строковый вариант отклоняла схема `type: integer`. В результате операции модерации,
обновления и выборки обращались к несуществующему объявлению.
