# Глоссарий проекта

Специфичные для проекта термины, аббревиатуры, кодовые названия. Помогает агенту правильно интерпретировать задачи и переписку.

## Термины

| Термин | Значение | Контекст |
|--------|----------|----------|
| Кабинет | Рекламный аккаунт Директа с собственным логином | `client_login`, `YD_DIRECT_TOKENS`, `yd_direct_accounts_get` |
| Агентский аккаунт | Аккаунт агентства, управляющий субклиентами через заголовок `Client-Login` с одним токеном | `YD_LOGIN`, `YD_ALLOWED_LOGINS` |
| Субклиент | Клиент агентства, выбирается логином в `Client-Login` | инструменты Директа |
| Самостоятельный кабинет | Кабинет без агентства, у которого свой OAuth-токен | `YD_DIRECT_TOKENS=логин:токен` |
| Sandbox | Тестовый контур Директа с отдельным хостом | `YD_SANDBOX=true` |
| Read-only режим | Все мутирующие инструменты блокируются до сети | `YD_READONLY` |
| Confirm-режим | Мутация без `confirm=true` возвращает превью | `YD_CONFIRM` |
| Partial-success | Разбор per-item ошибок пакетного ответа Директа в поле `_partial_success` | `annotate_partial()` |
| Units (очки) | Баланс запросов Direct API из одноимённого заголовка ответа | лог, WARN при < 5 % |
| ExternalId | Кодировка условий ретаргетинга: цель Метрики как есть, сегмент Метрики +1 000 000 000, автосегмент +1 500 000 000, сегмент Аудиторий +2 000 000 000 | `yd_retargeting_lists_add` |
| Lookalike | Сегмент Аудиторий из похожих пользователей | `yd_audience_*` |
| Folder ID | Идентификатор каталога Yandex Cloud, нужен Wordstat API | `YC_FOLDER_ID` |

## Аббревиатуры

| Сокращение | Расшифровка |
|------------|-------------|
| MCP | Model Context Protocol — протокол инструментов для AI-ассистентов |
| YD | Префикс переменных и инструментов проекта (Yandex Direct) |
| YC | Yandex Cloud |
| IAM | Identity and Access Management — токен Yandex Cloud, обмен из OAuth или Api-Key |
| OAuth | Токен Яндекс ID с правами `direct:api`, `metrika:read/write`, `cloud:auth`, Аудитории |
| CRM-данные | Email, телефоны, ID устройств для сегментов Аудиторий |
| TTL | Время жизни IAM-токена, берётся из `expiresAt` |
